# Seller: Metacortex

TEST DATA ONLY. Metacortex is the fictional software company from the film
"The Matrix"; the case studies, clients and URLs (example.com) are invented
for the demo. The seller name above becomes the dossier section
"Metacortex angle". Format: one "## <id>: <title>" section per case.

## cs-01: Scaling an event-analytics pipeline for a SaaS product
- Industry: SaaS
- Technologies: ClickHouse, Kafka, Kubernetes, Python
- Problem: Single-node analytics database hit limits as event volume grew.
- Result: Moved to a horizontally scaled ingestion and storage setup.
- URL: https://example.com/case-studies/event-analytics-scaling

## cs-02: Managed data warehouse migration for a small B2B SaaS team
- Industry: SaaS
- Technologies: PostgreSQL, BigQuery, dbt, Airflow
- Problem: Reporting queries on the production PostgreSQL slowed down the product.
- Result: Analytics moved to a managed warehouse with scheduled transformations.
- URL: https://example.com/case-studies/warehouse-migration

## cs-03: Container orchestration for a self-hosted product
- Industry: SaaS
- Technologies: Docker, Nomad, Terraform, Hetzner
- Problem: Manual Docker deployments on several servers were hard to keep reliable.
- Result: Deployments automated with an orchestrator and infrastructure as code.
- URL: https://example.com/case-studies/container-orchestration

## cs-04: Fraud-detection model for an online store
- Industry: E-commerce
- Technologies: Python, scikit-learn, AWS SageMaker
- Problem: Rising chargebacks from fraudulent card payments.
- Result: Risky orders flagged before payment confirmation.
- URL: https://example.com/case-studies/fraud-detection

## cs-05: Security hardening of a checkout flow
- Industry: E-commerce
- Technologies: Content Security Policy, Subresource Integrity, Node.js
- Problem: Third-party scripts on payment pages could be modified without notice.
- Result: Script integrity checks and monitoring added to checkout pages.
- URL: https://example.com/case-studies/checkout-hardening

- Industry: HealthTech
